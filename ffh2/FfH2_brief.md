# FfH2/概要

- 対象: FfH2本家（BtS 0.41o）。OACでは変更されている場合あり
- 出典: http://kentasis.web.fc2.com/FfH2/brief.htm

Fall from Heaven IIはCivilization IVのダークファンタジーMODです。

氷の時代は終わり、かつての大帝国の生き残りの人々は、今では小さな部族と成り果てました。失われたものを取り戻し、再建する準備が整いました。しかし世界は空っぽではありません。蛮族の大群がこれらの新しい文明を待ち受けています。野生の動物たちは不幸な斥候や無茶な偵察者たちに忍び寄ります。ジャイアントスパイダーはジャングルや森林で彼らの獲物が致命的な最後の一歩を踏み入れるまで辛抱強く待ち続けます。

そこには偉大な悪の文明や、無欲の善の文明もまた存在します。中立の文明も現れ、世界は再びバラバラになり、思想に反対するものたちが互いに生き残りを賭けて競いあいます。第1の目標は、生存することです。第2の目標は、善かれ悪しかれ、国力を持つことです。あなたは軍備や魔法の探求を通して、あるいは信仰や神への冒涜を通して、国力を追求することでしょう。あなたが選ぶそれぞれの道の選択には味方するものもいれば敵対するものもいます。そしてより深く調べていく秘密は、戦闘なのか魔術なのか神術なのか、深く調べるほど後戻りはできにくくなるでしょう。

Fall from Heavenの新機能のいくつかを以下に列挙します:

魔法！ : 呪文を唱えることができるユニットは、マナ毎によって違う戦闘スキルを得ることができ、彼らは新しい呪文を唱えることができます。呪文を唱えることができるユニットは魔術師・召喚術師・神術を唱える信奉者たちの3つに分類できます。ユニットが唱えられる呪文は、供給されているマナによります。15種類のマナ(炎、エントロピー、自然、精神など)の中から唱えたい分野のマナを得ているならば、ユニットがレベルアップした時に新たな呪文を覚えることができます。呪文を唱えることができるユニットは、ゆっくりですが勝手に経験値を得ていきますので、戦闘で危険にさらす必要はありません。

経験値 : ベテランのユニットに価値を持たせました。基本的な戦闘スキルは効果が2倍になっており、経験を積んだユニットと新米ユニットの違いを大きくしました。また、種族ごとへのアンチとなる戦闘スキルも加えました。もし望むのであれば、エルフたちを苦しめることもできるでしょう。

アップグレード : より強いユニットへアップグレードするには、そのユニット自身が強いことが証明されなければいけません。絶対に死なず、永遠に戦い続ける不死の戦士へなりたいのであれば、そのユニットは鉾鎚兵で最低でもLv6以上が必要となります。

宗教 : すべての宗教が異なっています。そして、それらのいくつかがあなたの文明の属性を変更するでしょう。もし青褪めたヴェールを国教とするならば、あなたの文明は悪属性になるでしょう。しかし悪魔たちの凄まじい魔力や知識、さらには悪魔からの援助が与えられるでしょう。一方でキルモフのルーンを国教とするならば、ドワーフたちの協力が得られ、彼らの愛する金や宝石を共有することができるでしょう。

英雄 : 暗黒と不和の時代に、英雄は、自らの文明を勝利に導くために立ち上がるでしょう。英雄は世界ユニットで、一度きりしか作成することができません。もし彼らが死んでしまえば二度と現れることはないでしょう。各文明や各宗教には少なくとも1人の英雄がいます。英雄は毎ターン、経験値を得ていきます。これの意味するところは、例えどんなゲームでも彼らはとても強力なユニットになるということです。彼らは小さな都市であれば簡単に陥落させることができます。彼らが死なないような戦場をうまく探し、彼らを守って下さい。

テクノロジー : ここはとても重要な部分です。にもかかわらず第1層や第2層のテクノロジーをまんべんなく開発しているかもしれません。たぶん、戦闘か魔法か宗教かなにか1つに特化した方がいいかもしれません。FfHにおいてテクノロジーの進行はゆっくりです。それは得たテクノロジーの効果が発揮される時間をもたせるためなのです。また宗教ごとの固有のテクノロジーは、国教を採用しない限り研究することができないでしょう。
