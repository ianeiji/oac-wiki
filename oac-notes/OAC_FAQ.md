## FAQ

当サイト内では記載のない細かな仕様変更もできる限り記載するように努めていきます。

#### 開発版と安定版どっちがいいの？

基本的に開発版を選ぶのをお勧めします。

安定版は元々更新が頻繁に成されていた時期に、開発の一区切りとして大規模な変更の前にその時点での不具合の洗い出しのために設けられた基準点であり、直後のバージョンと比べて動作やバランスが安定していることを示していました。 / ただし開発版が0.56に達して更新が途絶えた現在では、バランス調整があらかた終了していることや、時が進んで発見された古いバグが開発版では潰されている一方で安定版では野放しと言うこともあり、安定性においてはむしろ開発版の方が勝っているとも言えます。 / そのため安定版を選ぶのは、各バージョンアップの特徴を参考に安定版(0.49)と開発版(0.56)の違いを見比べて、開発版よりも安定版に大きな魅力を感じる場合に限ります。

#### 非公式開発版と開発版どっちがいいの？

基本的に非公式開発版を選ぶのをお勧めします。

というのも非公式開発版はバグ修正とAIの調整を目的に作られた物だからです。途中からはバランス調整と言う名の内容の変更に踏み入れていますがそれが嫌だという方でも「Patch6」を当てることを推奨します。戦闘アニメーションをカットしたくない方も「Patch12」までは当てて下さい。以降は内容の変更が多く、特に「Patch17」は大幅に手を付けているため好みの問題ですが、不具合修正が進んでいることは変わりありません。変更内容の詳細はここの配布場所にてReadMe.txtを読んで下さい。

#### 「○○でウイルスをスキャンできません」となりダウンロードできません。

OneDriveの仕様により一部拡張子のファイル入手を制限される場合があるようです。解決方法は不明ですが回避は可能です。

複数のファイルをまとめてダウンロードすることで回避できます。フォルダごと、あるいは複数のファイルにチェックを入れた状態でダウンロードを選択して下さい。ZIPファイルとして圧縮された状態でダウンロードされますので解凍して中身を取り出して下さい。

#### 配布ファイルを入手したけれど「このファイルを開けません」となり困っています。

OACのファイルはRARファイルや分割ZIPファイルで配布されています。 / いずれも圧縮ファイルですから使用するためには予め解凍する必要があります。さらにいずれもウィンドウズ標準では解凍できないので、対応する解凍ソフトを用意する必要があります。

RARファイルの解凍はWinRAR (開発元・無料版有り)・Lhaplus (フリーソフト)・Explzh (フリーソフト)などが対応しています。

分割ZIPファイルの解凍は7-Zip (フリーソフト)などが対応しています。

#### ファイルの解凍が上手くできません。

「xxxxxxxxx.part1.rar」「xxxxxxxxx.part2.rar」というファイルや、「xxxxxxxxx.zip.001」「xxxxxxxxx.zip.002」というファイルはまとめて1つのファイルであると考えて下さい。

これらの連番ファイルを同じフォルダに格納し頭のファイルを選択することで展開可能です。以降の番号は自動的に一緒に解凍されます。 / 片方だけでは解凍できません。必ず同じフォルダに格納した上で解凍して下さい。

#### ゲームが起動途中でフリーズします。

ReadMe_oac.txtの「MODが起動しない場合」および「Fall from heaven 2と両立させる方法」は読みましたか。

もしエラー内容が"GFC Error: failed to initialize primary control theme"であるならば解決するはずです。

#### ver.0.30/0.30aでプレイ開始時にクラッシュします。

バグです。最新のdパッチを当てるか、他のバージョンでのプレイを推奨します。

#### 起動はするけれどプレイ開始のマップ生成時にクラッシュします。

どうやら環境依存であり、作者を含む多くの人の環境で再現しません。ゆえに原因が不明であり、1つとも限らないため個別に対処をお願いしています。対処法は以下に記します。

1. 原因がOACにあるとは限りません。BtS単体やMODMODなしのFfH2、別のマップスクリプトなどを試してみましょう。
2. ブルーマーブルとの競合が疑われます。以下に解決法を ReadMe_oac.txt より引用します。 Blue Marble: Blue Marble for Fall from Heaven 2を導入している場合は、OACインストール後に再度、Blue Marbleをインストールフォルダに上書きしてください。それでも改善しない場合は、Blue MarbleをそもそもインストールしないことでCTDを回避できる可能性があります。
  - なお簡易パックの中にはブルーマーブルのマージされたものがあり、この場合も同様の症状が出る可能性があります。
3. 以下のパッチを当ててみて下さい。DARにて置き換えられているOceanGrids.ddsを元に戻す*1パッチです。
  - http://www1.axfc.net/uploader/so/2823070.zip?key=civ4
4. 「起動画面の背景を設定で変更したら落ちるようになったけど戻したら直った事がある」との報告あり。
5. 「タイル格子を表示する設定にしたら落ちた」との報告あり。MODを使わず起動した上で格子表示を解除してみて下さい。
6. ver.0.30および0.30aにはクラッシュバグがあります。
7. それでも駄目な場合は環境をできる限り明らかにした上で報告すれば何とかなるかもしれません。

#### プレイ開始時に多数のエラーログ表示があります。

原因はUAC(ユーザーアカウント制御)とBUGMODの干渉です。FfH2がProgram Files上でしか動かないため個別に対処をお願いしています。 / 結果としてBUGオプションの記録ができなくなっています。対処法はUAC(ユーザーアカウント制御)による制限の回避方法をご覧下さい。なおBUGオプションをいじるつもりが無いなら放置も手の1つです。

ログ表示に収まらずポップアップが延々と出現する場合は CivilizationIV.ini の HidePythonExceptions を1に戻すか、放置以外の解決法を取って下さい。

#### BUGオプションの変更が有効にならないのはなぜ？

UAC(ユーザーアカウント制御)による制限の回避方法をご覧下さい

#### ver.0.24以前からプレイしているのですが、栄誉の殿堂が正常に表示されません。

ver.0.25にて「楽園への扉」の勝利条件が廃止されたことで、栄誉の殿堂に同勝利が記録されている場合は正常に表示されなくなります。 / 対処法をOACさんのテキストから引用して記します。

このエラーを改善する場合は、 / [\My Documents\My Games\Beyond the Sword(J)\Replays] / にある楽園への扉勝利したCivBeyondSwordReplayファイル(※)を選んで消してください。 / ※よくわからない場合は、～.CivBeyondSwordReplayをすべて消してください。

#### 都市を落としても選択肢が出ずに必ず破壊してしまいます。

FfH2 0.41の”o”パッチを当て忘れている場合にそうなるようです。

### 作者への報告

報告場所はバグ報告フォーラムになります。 / OAC フォーラムの バグ報告 トピックに 返信 する形で書き込みをするのが望ましいです。原因がDARにあった場合でもDenevさんが返信してくれます。 / 公式には上記の通りですが既に開発を終了しているため応えてくれるとは限りません。現在は当サイトの管理人が非公式に対応している状況なので、サイト管理人にコンタクトを取るか5chのFfH2スレに書き込めばできる限りで対応します。

報告の際にバージョンをきちんと表記しましょう。最新版であっても誤解を避けるためにバージョン表記を使うことをお勧めします。

#### どんなことを報告すればいいの？

クラッシュしたりフリーズする深刻なバグに遭遇した場合は是非ご報告お願いします。 / 再現性の確認や発生状況の特定がされていない既知の問題が存在する場合に、再現方法の報告ないしセーブデータを提供して頂けると大変有り難いです。 / その他小さなバグから気になることまでどうぞお気軽に。

報告の前に既知の問題や、バグ報告フォーラムの最近の過去ログをご一読頂きたい。問題の起きたターン付近のセーブデータを残しておけば、後々役に立つかもしれません。

#### データを上げるときに気をつけるべき点は？

1. セーブデータが保護されていないかの確認
  - オプション「Assetsフォルダの保護」にチェックが入っている場合は、Assetsフォルダの中身が完全に同一でないとセーブデータを開くことができません。細かなファイル構成の違いで動作しなくなるため、提供して頂いたデータにアクセスできない可能性が高いです。
  - セーブデータでプレイ中に「勝利条件」ウィンドウの「設定」タグ、「オプション」項目にて確認できます。
  - なお「Assetsフォルダの保護」はそれを必要としている人を除いて不要なオプションです。特に理由がなければチェックを外してプレイすることをお勧めします。
2. MOD構成の表記
  - 当然ながらバージョンの表記は必須です。
    - 最新版であってもバージョン表記を使いましょう。更新が早いので入れ違いが起きる可能性があります。
  - あなたの環境におけるMODフォルダ名(「Fall from Heaven 2」など)を表記しましょう。
    - セーブデータを正常に開くためにはフォルダ名を揃える必要があります。表記が無くとも確認は可能ですが手間がかかります。
3. 利用するアプロダ
  - データはCiv4アップローダ、画像はCiv4wiki画像掲示板をお勧めします。

#### マルチプレイで問題を発見しました。

マルチプレイはサポート対象外の模様。 / 気が向いて、かつ対処法が分かれば対応するとのことですが、あまり期待しないで下さい。 / 同期エラーの頻発に関してはDenevさんの見解を以下にフォーラムより引用します*2。

同期エラーの原因特定は非常に難しく、正直言ってお手上げの状態です。 / サイバーフロントのサポートページ（http://www.cyberfront.co.jp/support/support.html）には、ランダムイベントを無効化するという対策があります。 / ひとまずこれを試してみていただけないでしょうか。 / ただ、FfH2は多くの実装にランダムイベントのシステムを流用しており、これを無効化すると多くの機能が働かなくなります。（たとえば適応志向の志向選択など） / この点はご了承ください。 / / そのうち、なるべくランダムイベントに頼らない実装に換装したいと思っていますが、いつになるかは全くの未定です。 / / また、DARやOACには本当に多くの改変が加えられており、その中のいずれかが同期エラーの原因となっていることも考えられます。 / その場合ご期待には添えないかもしれません。

志向選択に関してはランダムイベントを無効にしても働くように0.30 (DAR0.59)にて仕様変更が行われています。

### ゲームプレイ上の疑問

#### 宗教の祭殿(ノクス＝ノクティスなど)が機能していないようだけど？

祭殿の効果の一部は国教に採用していないと機能しません。詳細は宗教データのページをご覧下さい。 / 宗教関連は他にも宗教建造物にも制限がかかったり国教採用による属性変化が固定されないなど、シヴィロペディアに記載されていない細かな変更が多数あります。

#### 蛮族志向なんだけど、こちらから蛮族の国に宣戦布告するにはどうしたらいいの？

宣戦布告効果のある魔法を使いましょう。攻撃魔法ならば蛮族の国領内の蛮族ユニットを、タイル魔法ならば蛮族の国領内のタイルを巻き込む形で使用すればOKです。 / 竜巻や炎の輪あるいは放火や日照りなど宣戦布告の警告のポップアップの出る魔法が有効です。 / なお宣戦布告効果のある攻撃魔法でも、そのユニットの属する領内で食らった場合を除いて宣戦布告効果は機能しなくなりました。

#### 蛮族との和平が突然途切れたんだけどなぜ？

蛮族志向による蛮族の国(オーク蛮族)との友好ならば文明のスコアが2位の1.5倍以上に達した時点で友好が破棄されます。あるいは1つ上の項で述べているように宣戦布告効果のある魔法の使用でもやはり友好が破棄されます。 / これはFfH2バニラでも同じですし、イベントポップアップが出現するので問題はないでしょう。また蒼褪めたヴェールによる魔族蛮族との友好関係は改宗により破棄されます。この場合も通知されません。 / そして、その他にも通知されない蛮族との友好破棄がありますので説明します。

（以下は0.56の非公式開発版では起こらないようになりました） / おそらく永久同盟を組んだり属国を抱えたことが原因です。 / 通常の文明は蛮族とは永久戦争の関係にあります。そして蛮族との友好も宗主国/属国や永久同盟による戦争巻き込みの影響を逃れることはできません。つまり対象蛮族と友好関係を結んでいない文明を自発属国にしたり永久同盟を組むと友好が破棄されるわけです。 / なお破棄された友好の再構築は基本的にできません。相手国の滅亡や関係の解消は無意味です。改宗により友好を結び直すことができますが、逆に改宗により戦争が開始されることもあります。
