# OAC/Tips

- 対象: OAC の解説ページ
- 出典: http://kentasis.web.fc2.com/OAC/Tips.htm

## Tips

知らなかったり使わなくとも困らなかったり状況を大きく左右することはないけれど、使えると楽になるプレイ上のコツや、豆知識、小技をまとめる。

### マップマーキング

都市出しや都市改善の計画などに役立つマップへのマーキング技がOACでは使える。 / OAC特有の機能ではなくBtSやBUGMODなどにも付いている機能だが一部はより洗練されて使いやすくなっている。

#### Alt-S

Alt-S*1はマップ上の1タイルに標識を立てるコマンド。 / BtS標準で使える機能。通常の手順は非常に面倒くさくて使いづらいので、このショートカットを覚えることをお勧めする。 / また、非常に短時間のマーキングの場合はPキーによる発信コマンドも使える。

使い方の一例

- 隣接制限のある地形改善を整備する予定地
  - 主に砦で使うと役立つ。マーキングなしで最適な砦スパムをするのは至難の業。
  - バンノールやラヌーン (海賊の隠れ家)、ニバル (雪だるま)など2タイル制限のタイル整備で役に立つ技術。1タイル制限のタイル整備で行うと乱立しすぎて逆に判りづらいかも。
- 巨大蜘蛛の住処
  - 近寄ると喰われる巨大蜘蛛だが偵察ユニットにしか見えないため存在を忘れてしまいがち。
  - 当然だがユニットは動いたり死んだりするので過信は禁物。なお、他の動物と合流したなら合流した動物を見ていればいいし、誰かを捕食をするために移動した場合も、タイルが視界に入っていればそのターンに限り確認できる。
- 灌漑の延長
  - 農場資源や農場を張りたい立地に向けて灌漑を延長させる予定があるなら、その経路を予め示しておくのも手。
  - 経路が長くなってくると標識が乱立して面倒だし判りづらくなるので線を引いた方がいい (F11からの戦略レイヤー)。
- 都市の役割分担
  - 都市名の編集でも対処できるが、変更したくない場合に。
- 都市建設予定地
  - 別に紹介するAlt-Xの方が使い勝手がいい。

余談だが名所旧跡についているラベルも同じ手段を用いており、名所旧跡のラベル上書きは出来ないように制限されている模様。

#### Alt-X

Alt-X*1はマップ上に都市圏を示す図形標識を立てるコマンド。 / 都市圏のサイズは2で固定であり大都市志向には対応できない。

使い方の一例

- 都市建設予定地
  - 別に紹介するAlt-Sを使ってもいいが、こちらの方が使い勝手がいい。
  - 都市を建て終わった後も邪魔でなければ、都市圏の明示のために置いておくと良い。
- ライバル文明の都市マーク
  - 文化圏からライバル都市の存在が確認できるが、都市そのものが見えない場合に。
  - 都市数が少なく文化が小さい間は文化圏から都市の配置を類推できるが、その内どこに都市があるか判らなくなるので判る内にマーキング。
  - BUGMOD単体だと暗闇への設置ができないので使えなかった技。
- 名所旧跡の捜索
  - バグ技あるいは裏技の範疇なので自身の良心が許すなら。
  - 設置モード中に暗闇タイルを走査するとマップ上の標識がうっすらと見える。最初から立っている標識とはすなわち名所旧跡のこと。一部の名所旧跡は実際に周囲に設置することで標識の中身まで見える。

### 蛮族湧き

何もないところから湧き出てくる蛮族。この現象は規則に従って起きているので、規則を知れば湧きを最小限に抑えることもできる。

視界外から出現する蛮族ユニットは、下のいずれかを満たすタイルからは湧き出さない。

1. 文明の視界内 (蛮族の視界は無視) / ちなみに文明の視界とは、文明に所属する各ユニットの視界と各都市の視界の合算のこと。一時的に出現するユニットは次の自分のターン開始まで残るので、鷹や浮遊する目によって確保された視界も有効。
2. 既存のあらゆるユニットから2マス圏内 (蛮族ユニットを含む) / ここでいう2マスは新規都市出し制限などと同じく四角形の範囲であり、斜め方向に2マス離れた範囲も含む。
3. 陸地に接しないタイル (非沿岸海洋)
4. 通過不能なタイル (山岳や氷棚など)

視界外に出現する蛮族都市は、下のいずれかを満たすタイルには作られない。

1. 文明の視界内 (蛮族の視界は無視) / ちなみに文明の視界とは、文明に所属する各ユニットの視界と各都市の視界の合算のこと。一時的に出現するユニットは次の自分のターン開始まで残るので、鷹や浮遊する目によって確保された視界も有効。
2. 既存のあらゆる都市から2マス圏内 (蛮族都市を含む) (海洋を隔てた都市に関しては未調査)
3. 水タイル
4. 通過不能なタイル (山岳や氷棚など)

ユニット湧きは既存のユニットにより大幅に抑えられる。特に蛮族ユニットによる制止も効くので蛮族砦や強力な野生動物も活用できる点が良し。あるいは鷹による視界確保は非常に有用。自動派遣も利用すれば安定して防止することが出来るし、古代の塔と組み合わせれば非常に広範囲を楽にカバーできる。なお、古代の塔に関しては飛行ユニットであれば良いので召喚したグリフォンも有効。

なお、オルタスなどのイベント出現蛮族やヒポグリフ・クラーケンは別の規則に従って出現するので上記に当てはまらない。

### 視野

大都市志向や広大な貧民街を建てた都市で3タイル目の市民配置変更に困ったときは"視野"を調整してみよう。メインスクリーンの右上にあるスライダーで変更できるこれは、ズームとは異なり都市画面にも影響を及ぼす。数値を大きくすれば視野が広くなり都市画面に入ったときでも引いた位置から眺められる。適切な数値に設定すれば3マス目の市民配置はもちろん産出数値の確認も出来るようになるだろう。

もしも視野を調整するスライダーが見当たらない場合はオプションでオフになっている。BUGMODの設定を開いて（Ctrl-Alt-O*1）、マップ→その他→"視野"にチェックを入れよう。調整したはずの視野がプレイの度に戻ってしまう場合は"視野を記憶"にチェックしよう。

### 影の修正

WBで山岳を丘陵に変えたり、海峡を陸地で繋いだり、平地の都市を丘陵にしたりしたことはあるだろうか？そうしたタイルの見た目に違和感を感じたことはなかろうか？WBを使ったことがなくてもカザードの世界呪文「母なる鉱脈」により丘陵に変化したタイルで同様の違和感を感じたことがある人はいるはず。これらは影の描写に問題があるために発生するので影を修正すれば元に戻る。

影の修正は「Ctrl-D*1」のコマンドで呼び出せる [Debug Menu] の [Graphics] タブにおいて [Rebuild Terrain Right] にチェックを入れることで可能。何か見えてはいけない物が見えたり操作できたりするチートコマンドではないので、通常プレイの最中でチートを使いたくない場合でも安全に利用可能。

### 動作確認

ゲームルールの詳細を調査したり、AIの動作チェック、AIプレイの観戦などに利用できる機能をまとめる。 / これらは通常プレイの最中には使用しないが、ゲームの合間の息抜きやより細かな仕様の理解などに使える。

#### World Builder

「World Builder」（ワールドビルダー）はCiv4標準装備の調査ツール。[Ctrl-W*1]で呼び出せる。OACに置いても機能面で変更された点はないが、非公式開発版に限り追加された機能があるので、ここではそれを紹介する。

- ユニットを編集
  - ダメージ量を変更可能。ダメージが100に達したユニットは死亡する。一旦100を入力するとユニットの死亡処理が行われて値を戻しても元には戻らないので注意。
  - 守りを固めたターン数を変更可能。守りを固めることの出来ないユニット（騎乗兵など）の場合は変更が反映されない。
  - 信教を変更可能。通常は信仰を持たない無機物でも反映される。
- 都市を編集
  - 叛乱期間を変更可能。最大100ターン。
- 都市の接収
  - 「プレイヤーモード→建造物→都市を建設」により他国都市を選択することで平和的に接収できる。

#### Shift-4

Shift-4*1は操作プレイヤーの国庫資金を+1000増加させるチートコマンド。資金の操作はワールドビルダーでも可能だが、オートプレイ稼働中でもワンステップで行え、ワールドビルダーで存在する上限(5000)もないので厳格な目標額がないのならばこちらの方がお手軽。

#### Shift-Ctrl-E

Shift-Ctrl-E*1はランダムイベントの調査ツール。イベントの発生状況を満たす必要はあるが、通常は発生に運が絡みテストしづらいランダムイベントを簡単に起こすことができる。

#### Shift-Ctrl-X

Shift-Ctrl-X*1は入力したターン数だけ、AIに操作を委ねるオートプレイコマンド。オートプレイ中の思考は通常AIと同じだがハンデは人間と同じ*2になる（同盟したAIと同じような形）。 / 同じようにShift-Ctrl-M*1は1ターン限定のオートプレイコマンド。こちらはターン数を入力することなく1ステップで開始される。

これを使えばAIの挙動を確認したり、AIオンリーのエレバスを眺めたり出来る。操作文明が滅んでしまえばそこで終了となるので、開始前にWBで盛り立ててあげたり氷棚で隔離したりと手を加えることもある。オートプレイ中の勝利や敗北なども、栄誉の殿堂や戦果の殿堂にしっかりと記録されてしまう点は注意。 / ちなみに完全に人間の手の入らないエレバスの実現は簡単ではない。オートプレイの終了ごとに他国から外交の手が伸ばされるので、そこで人の手が介在してしまう。それを避けようとオートターン数を伸ばすと、何が起きたか確認しづらくなるし、マップ中にポップアップアイコンが残って挙動が重くなる。

なおCivilizationIV.iniのAutorunの数値を1に設定するとプレイ開始早々からオートプレイが開始される。こちらでは勝利者が決まるまでオートプレイを止める手段が[Pause/Break]キーに限られ、WBでの介入はPause中に可能な範囲に限られるが戦果の殿堂には記録されない。

#### Ctrl-Z

Ctrl-Z*1は丸見えモードに移行させるチートコマンド。通常プレイでは見えてはいけない物がいろいろと丸見えになる。見えるだけで数値などを弄ることは出来ないが、このモードのままでプレイを続行可能。よってオートプレイとの相性が良い。オートプレイ稼働中に変更することも可能。 / 見えてしまう物はいろいろとあるが、例えばマップ情報は操作文明の視界や可視化条件などを無視して全て丸見えとなる。ライバル文明の研究や都市情報も全て閲覧可能。

#### Shift-Ctrl-L

Shift-Ctrl-L*1は操作プレイヤーを変更するコマンド。動作確認やCtDポイントの調査、オートプレイ中に操作文明が滅びそうで乗り換える時に使える。

#### Shift-Ctrl-P

Shift-Ctrl-P*1は操作プレイヤーを担当する指導者や文明を変更するコマンド。通常想定されない状態変化でさすがにいろいろと不具合があるので動作確認というよりは変わったプレイを経験したい方向け。

*1

キーの同時押下。例えば「Alt-S」ならAltキーを押しながらSキーを押下すること。

*2

一部はAI用のハンデが適用される。例えば訓練施設の費用割引など。
